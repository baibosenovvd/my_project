# Сквозная аналитика AZ GROUP

Внутреннее веб-приложение: путь заявка → оплата → участие по каждому каналу продаж, расходы и стоимость оплаченного участия (CPS).

Сейчас в репозитории — **схема базы и стартовые данные** (шаг «Как вайбкодить», п. 1 ТЗ). Экраны строятся после проверки схемы.

## Запуск

```bash
npm install
cp .env.example .env        # указать DATABASE_URL
npm run db:migrate          # создать таблицы
npm run db:seed             # каналы, олимпиады, настройки (повторный запуск безопасен)
npm run db:studio           # посмотреть данные в браузере
```

## Что в базе

| Блок | Таблицы |
|---|---|
| Справочники | `channel_groups`, `channels`, `tags`, `source_answers`, `olympiads`, `events`, `schools`, `plans` |
| Клиенты и продажи | `families` → `children` → `leads` → `registrations` → `payments` → `participations` |
| Расходы и трафик | `expenses`, `ad_stats`, `b2b_activity`, `reach_stats` |
| Система | `settings`, `users`, `import_batches`, `audit_log` |

Сиды (`prisma/seed.ts`):
- 6 групп A–F и 22 канала из карты каналов + служебный `UNKNOWN`;
- 12 ответов «Откуда узнали» и канал для каждого;
- Fibonacci и Atlantia (25 000 ₸, план 10 000 участий), даты сезона и финалы;
- школа Zerdeli (партнёр, особая цена 20 000 ₸) и постоянные метки `DARYN`, `SCH-ZERDELI`, `IG-FIB`, `TG`, `SITE-FIB`;
- настройки: целевой CPS 5 000 ₸, кэшбек 5 000 ₸, пороги автоподсказок.

Статусы каналов из карты: ✅ и ⚠️ «не системно» → `active`, ⏳ и ❌ → `not_launched`, ⏸ и ⛔ → `paused`.

## Решения сверх ТЗ

- **`channels.funnel_type_override`.** ТЗ задаёт шаблон воронки на группу, но в группе B промо и квизы — `b2b`, а выставки и мероприятия — `own`. У группы B стоит `b2b`, у EXPO и EVENTS — переопределение на `own`.
- **`source_answers`** — справочник «ответ → канал» для правила 2 из раздела 4, чтобы менять соответствие в настройках, а не в коде.
- **`reach_stats`** — ручной ввод охвата для воронки `own` (контакты в базе → охвачено). В разделе 3 такой таблицы нет, а воронка из раздела 5 без неё не строится.
- **`leads.answer_channel_id`** — канал по ответу родителя хранится отдельно от итогового, чтобы видеть противоречия «на проверку».
- **`payments.family_id`** — платёж привязан к семье; один платёж может покрывать несколько участий (средний чек).
- **`settings`** — одна строка с порогами (CPS, кэшбек, автоподсказки, 70% плана, 10% UNKNOWN, 2 дня без оплаты, 50% для финалиста).
- **`users`, `import_batches`, `audit_log`** — вход с 2FA, предпросмотр импорта и журнал действий из разделов 6 и 8.
- Деньги — `Decimal(14,2)` в тенге. ИИН — только `children.iin_hash` (HMAC-SHA256 с ключом `IIN_HMAC_SECRET`).

## Нужно уточнить

1. **Предметы Atlantia.** В ТЗ «5 предметов» без названий. Сейчас 24.10.2026 заведена одна дата без предмета; нужна отдельная запись на каждый предмет, иначе ребёнок не запишется на два.
2. **«Астана дарыны» нет в списке «Откуда узнали».** По карте канал считается по этому полю, но подходящего варианта нет — ответ уйдёт в «От завуча или учителя» (ZAVUCH). Добавить вариант «Рассылка «Астана дарыны»» или считать только по ссылке с кодом `DARYN`.
3. **«От завуча или учителя»** сейчас → ZAVUCH. Если учителя-координаторы (TEACHER) заработают, вариант стоит разделить.
4. **«Выставка или мероприятие»** → EXPO. Свои мероприятия (EVENTS) по ответу от выставок не отличить — только по коду.
5. Даты финалов, доля AZ GROUP, планы по каналам — открытые вопросы из ТЗ.
